# Lucid Sudoku

**Every move, animated.**

Lucid Sudoku is a visual sudoku tutor for iOS. It teaches you to see the puzzle the way experienced solvers do — every move is animated, and every animation has a reason. You don't get the answer. You get the thought process that leads to the answer.

- Eight techniques, from Naked Singles to X-Wings, each with its own canonical animation.
- A new hand-picked daily puzzle. Manual input for anything else.
- A practice mode that drills the techniques you're shaky on.
- VoiceOver, Dynamic Type, Reduce Motion — built for everyone.

**One-time unlock. No subscription. No ads. No tracking.**
